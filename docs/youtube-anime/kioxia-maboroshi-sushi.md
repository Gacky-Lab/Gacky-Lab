# 無職ミクの幻の寿司

歌のギャラはゼロ。でも今夜はお寿司。キオクシア株の含み益を見てイクラまで追加したミクに、テトがひと言。「もう売ったの？」

本編は3分05秒。1:57から初音ミクが箸をマイクにして、オリジナル曲『幻の寿司』を歌う。

本編に使ったのは、高値を追う心理、含み益を使えるお金のように感じる早合点、買い増しによる平均単価と保有数量の変化、売った後の値動きが気になる心理。寿司の注文、テトとの会話、スマホを逆さにする芝居、歌詞と旋律は今回の創作。

## 作中の計算

株価と注文はすべて架空。１株を10,000円で買い、11,200円で含み益1,200円。9,000円で１株買い増すと取得額は計19,000円、平均取得単価は9,500円。8,000円で２株売却すると受取額16,000円、手数料等を省いた確定損失は3,000円。その後に株価が9,500円に戻っても売却済みの損益は変わらない。

## 音楽

劇中歌『幻の寿司』はオリジナル。ミクの音域をサビで実際に上げ、「下がったのは晩ごはん」で旋律を下げた。歌とミクのセリフは初音ミク V6 ORIGINALをAI-VOCALOID-STUDIOからVOCALOID7で合成。テトのセリフは重音テト公式UTAU音源。日常パートのBGMはKK『なんでしょう？』トラック２〈へたっぴリコーダー版〉。[楽曲公式ページ](https://opentracks.com/bgm/detail/710)
