# 無職ミク、炊飯器になる。

初音ミクが炊飯器の起動音に応募する、重音テトとの非公式ファンアニメ。Gacky-Lab が制作した公開用カット（2分31.875秒）の調声・編集記録。

## VOCALOIDの調声データ

ミクの声は VOCALOID7 上の **HATSUNE_MIKU_V6_ORIGINAL**。各 VPR はテンポ120、四分音符480 tick。音程・歌詞・発音の長さは添付の譜面、返事の間やレンジの音は動画編集側で設定した。音源を入れた環境で各 VPR を開くと、打ち込んだノートを確認できる。

| VPR | 収録内容 | ノート数 |
| --- | --- | ---: |
| [採用試験の台詞](scores/rice_cooker_audition_dialogue.vpr) | 履歴書から深夜勤務までのミクの台詞。各テイクを分けて収録 | 265 |
| [早炊きのアリア](scores/rice_fast_aria.vpr) | 前半40秒が実技試験の歌。後半に「早炊き！」「声だけ先に炊けました」などの台詞 | 126 |
| [保温の子守歌](scores/rice_cooker_night_song.vpr) | 4秒ずつ6句。最後の2句は「眠れないのは」「中の人」 | 36 |
| [消音アナウンス](scores/rice_mute_announcements.vpr) | 「消音しました」を2テイク。二度目は上の音域で歌う | 16 |

### 「消音しました」の作り方

同じ8音節「しょ・お・お・ん・し・ま・し・た」に、下表の MIDI ノート番号を割り当てた。音節の開始は240 tick間隔。最初の7音は230 tick、最後の「た」は910 tick伸ばす。

| テイク | ノート番号 | 完成音声での使い方 |
| --- | --- | --- |
| 1回目 | 67, 72, 74, 76, 74, 72, 79, 77 | レンダリング音声の先頭から2.95秒、振幅1.95倍 |
| 2回目 | 72, 76, 79, 81, 79, 77, 81, 79 | 同じ音声の6.25秒地点から1.50秒、振幅2.50倍。語尾の途中で切る |

### テトの掛け合い

テトの台詞は重音テト公式UTAU単独音を音節ごとにつないだ。各サンプルのオフセットを適用し、再生速度倍率を 1.09、1.18、1.06、1.02、1.12、1.04 の順に循環。通常の音節は最大128ミリ秒、語末は最大180ミリ秒。ミクが言い訳している間にテトの返答が浮かぶ場面では、説明を足すより先に声を入れた。

編集上の基本の後ろ余白はテト90ミリ秒、ミク130ミリ秒。一部の反応には450ミリ秒を置く。素材自体の余白と16 fpsのフレーム丸めが加わるため、これらは実測の無音長とは異なる。

## 絵と音を合わせた箇所

- **1:22.1875**　『早炊きのアリア』開始から27.6875秒。「押せばすぐ炊ける？」の直後にレンジを鳴らし、「返事が速いだけ！」でパックご飯を食べるテトに切り替える。ベルは1475 Hzを主体に3740 Hzを重ね、発音付近だけ曲を最大53%下げた。
- **2:29.125**　2回目の消音アナウンスを途中で切ったフレームで、テープが貼られたミクの顔に飛ぶ。ここから終端までミックスは無音。顔を8フレーム（0.5秒）見せて「（無職に戻して。）」を字幕だけで出す。
