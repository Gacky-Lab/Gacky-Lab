# 無職ミクの制作マスター『睡眠１日30分』

今後の各話は、無職ミクの間抜けな日常の中に、観客が「やっぱり歌姫だ」と思う瞬間を一度だけ置く。この回では、寝返りで人気が出たミクが配信中に「おふとん空いてる　寝においで」と歌う。次の「枕のリンクは　概要欄」でいつもの調子に戻る。

## 毎話一度の歌姫カット

普段のミクは丸い白目に小さな点の瞳。正面か少し外向きが基本で、たまに寄り目になる。歌姫の一瞬は、同じ衣装・髪型・部屋のまま、青緑の瞳に柔らかい光を入れ、少し細めたまぶた、上がった頬、照れた笑い口を一緒に描く。下の絵を次話の作画参照に使い、表情は本編に入れる前に一枚絵で確認する。

![パジャマのまま、照れ笑いで歌うミクの表情基準](singer-smile.png)

次話の台本には「どの一言でこの顔になるか」と「次の一言で何に戻るか」を書き込む。歌の最中でも、思わず本音がこぼれた場面でもよい。この回では約1分25秒からの57フレーム（16 fpsで約3.6秒）。差し出す手と顔が両方入る画から約1.32倍までゆっくり寄る。顔の角度を固定し、語尾で指先が画面内に収まるよう構図を取る。歌詞テロップは残し、親指に重なる配信ラベルだけをこの一言の間外した。

## Blender工程

1. **声と間を先に決める。** ミクの台詞と歌、テトの返答、効果音、BGMを合わせ、各カットの開始フレームと尺を決める。基準回はBlender 4.5 LTS、横1280×720、16 fps、全2,600フレーム。
2. **元絵から動く部分を切り分ける。** 背景、人物、口形、瞳、手、小物を用途に応じて分ける。動かしたときに露出する背景まで補う。発話で顔の輪郭や背景まで揺れる全画面変形は使わない。
3. **話す人と聞く人を別に演出する。** 口は発話者だけ音声に合わせて切り替える。聞き手は要所で一拍遅れて視線を移す。この回では「お給料」でミクがテトへ、ラストではテトがミクへ視線を移し、「既読」でも黙ったまま。その間、白目の位置は固定する。
4. **動きには支点ときっかけを置く。** 指差しは肩・手首、歌唱は胸元の手と開く手のひらに別々のキーを打つ。布団は裾と枕を固定し、肩の上だけが息を吸うとふくらみ、吐くと沈むシェイプキーを使う。目覚ましを蹴る瞬間だけ短い跳ねを重ねる。
5. **歌姫カットは独立したシーンで作る。** 元絵の色を保つ発光マテリアルと正投影カメラを使う。口形、腕、手首に芝居を付け、カメラの正投影スケールをキーフレームで変えて寄る。差し出す手の五本の指と瞳の見え方を、字幕・配信表示を重ねた完成画で確認する。
6. **本編に戻して通す。** 歌唱カットを連番で書き出し、ビデオシーケンサーの元の尺に配置する。前後の一言を含めて再生し、表情の切り替え、点目の二重描画、口の差し替え跡、小物の縁、手と字幕の重なりを確認する。最後に音声付きMP4を全尺デコードして尺とフレーム数を照合する。
